# بطل التقريب ⭐

لعبة عربية للأطفال مستوحاة من التصميم المرجعي، تعمل بدون مكتبات أو تثبيت.

## التشغيل
فك الضغط وافتح index.html في المتصفح. أبقِ style.css وscript.js بجانبه.

## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا باسم rounding-hero على GitHub.
2. اختر Add file ثم Upload files.
3. ارفع الملفات بعد فك الضغط مباشرة في جذر المستودع، وليس ملف ZIP ولا المجلد الذي يحتويها. يجب أن يظهر index.html بجوار style.css وscript.js.
4. اضغط Commit changes.
5. افتح Settings ثم Pages.
6. ضمن Source اختر Deploy from a branch.
7. اختر main والمجلد /(root)، ثم Save.
8. بعد اكتمال النشر ستجد رابط اللعبة في صفحة Pages، غالبًا على النمط https://USERNAME.github.io/rounding-hero/ مع استبدال USERNAME باسم حسابك.

المرجع: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## المزايا
- التقريب لأقرب 10 أو 100 أو 1000.
- عشرة أسئلة مختلفة في كل جولة، و10 نقاط لكل إجابة صحيحة.
- تصحيح وشرح مباشر، دون خصم نقاط أو مؤقت.
- نتيجة نهائية وحفظ أعلى نتيجة لكل مستوى محليًا على الجهاز إن سمح المتصفح.
- تصميم مرن للهاتف والحاسوب، وأزرار تدعم لوحة المفاتيح.

## التعديل
النصوص والهيكل في index.html، والألوان في style.css، والمنطق والأسئلة في script.js.
تم التحقق برمجيًا من التقريب والخيارات والنقاط والجولات. لم تُجرَ معاينة داخل متصفح في هذه البيئة.
